## 🎯 Objectives
On Day 3 of our internship, we explored the **backend systems** that support South Eastern Railway’s administrative operations. This session focused on understanding the **hardware infrastructure**, **data storage mechanisms**, and **private cloud deployment** using IBM servers.

---

## 🧠 Key Learning Highlights
- Gained insight into how large-scale databases operate in real-world enterprise environments
- Learned how **IBM backend servers** support private cloud data used for **office-level and administrative operations**
- Understood how Oracle databases are deployed in secure, high-performance environments
- Explored **hardware-level specifications** of the servers currently in use at South Eastern Railway
- Discussed how computing resources are structured across multiple sockets and NUMA nodes for efficient data handling
